# 아이콘 디자인 컨셉

> 디자이너에게 그대로 넘기거나, 직접 디자인할 때 참고하는 명세서.

## 1. 한 줄 정의

**치지직 라이브 방송의 음량을 실시간으로 평탄화하는 크롬 확장 프로그램**

## 2. 전달할 핵심 메시지

> 들쭉날쭉한 음량이 균일하게 정돈된다

이 한 문장이 시각적으로 즉각 떠오르면 성공.

## 3. 사용자 페르소나

- 치지직을 자주 시청하는 한국 시청자
- 방송마다 다른 음량을 매번 손으로 조절하는 게 귀찮은 사람
- 갑작스러운 폭음·비명에 깜짝 놀라기 싫은 사람
- 게임/잡담/노래 등 콘텐츠 다이내믹이 큰 방송을 자주 봄

## 4. 시각적 메타포 후보

### ★ A. 파형 평탄화 (추천)

```
   ╱╲    ╱╲          ← 거친 입력 파형
  ╱  ╲  ╱  ╲
 ──────────          ← 평탄한 출력 (가운데/아래)
```

- 위: 진폭이 크게 변하는 파형(혹은 임펄스 두세 개)
- 아래: 매끈한 평행선 또는 진폭이 균일한 사인파
- 음향 도메인이 명확하고 "정규화" 메시지가 직관적
- 16px에서도 단순화 가능 (위 톱니 + 아래 직선)

### B. 레벨 미터

- 가로 또는 세로 레벨 바
- 바늘/지표가 안정적인 녹색 영역(목표 LUFS)에 머무름
- "안정성"이라는 정서적 메시지에 강함

### C. 이퀄라이저 위로 평행선

- 들쭉날쭉한 EQ 막대바
- 가운데를 가로지르는 평행선이 그 위에 정렬되어 있음
- "기준선으로 정돈" 시각화

### D. 스피커 + 흐름 (보조)

- 스피커에서 나오는 파동이 진행하면서 평평해지는 그래디언트
- 메타포로는 좋으나 16px에서 디테일이 사라지기 쉬움

## 5. 색상

### 권장 팔레트 (3색 이내)

| 역할 | 색상 코드 | 용도 |
|---|---|---|
| 베이스 | `#1F1F23` ~ `#2A2A30` | 어두운 배경 / 캔버스 |
| 강조 | `#00C73C` | 평탄화된 결과선·강조 (우리 ON 배지와 통일) |
| 보조 | `#F1F1F1` ~ `#FFFFFF` | 입력 파형·중립 라인 |

### 피해야 할 것

- 치지직(`chzzk.naver.com`) 공식 로고 / CI 그대로 사용 ❌
- 네이버 코퍼레이트 그린(`#03C75A`) 정확히 일치 ❌ (혼동 우려, 우리는 `#00C73C`)
- 4색 이상의 컬러풀한 디자인 ❌ (16px에서 무너짐)
- 사실적 그래픽 / 스큐모피즘 ❌ (모던 익스텐션 톤과 안 맞음)

## 6. 스타일 방향

- **Flat / Minimal Modern**
- 살짝의 그라데이션 가능 (128px에서만, 16px에서는 단색으로 fallback)
- 캔버스 모서리 둥글게 (radius 8~16% of canvas)
- 라인 굵기 일관성: 16px에서 1px 미만은 금물

## 7. 사이즈별 요구사항

| 사이즈 | 용도 | 디테일 수준 |
|---|---|---|
| 16×16 | 탭 옆 / 액션 영역 (메인 노출 위치) | 핵심 실루엣만, 디테일 다 버림 |
| 32×32 | 도구모음 HiDPI | 살짝의 디테일 |
| 48×48 | 익스텐션 관리 메뉴 | 중간 디테일 |
| 128×128 | 크롬 웹 스토어 카탈로그 | 풀 디테일 + 그라데이션·그림자 OK |

**워크플로우**: 16×16에서 인식 가능한 **하나의 핵심 형태**를 먼저 잡은 후, 큰 사이즈로 가면서 디테일을 더한다. 큰 사이즈에서 작게 줄이지 말 것.

## 8. 톤 & 무드

- **안정감 / 균형 / 차분함**
- 기술적이지만 친근한 (전문 DAW Pro 도구 느낌은 피하기)
- "조용히 일하는 도우미" 느낌. 강렬하거나 화려한 것 ❌

## 9. 빠른 폴백 (디자인할 시간 없을 때)

다음 중 하나라도 충분:

- **단색 텍스트 로고**: 어두운 둥근 사각형(`#1F1F23`) 위에 녹색(`#00C73C`) "AS" 또는 "AA" 두 글자
- **단순 도형**: 어두운 배경 위에 위쪽 톱니(흰색) + 아래쪽 직선(녹색) 단 두 요소
- **이모지 변환**: 🎚️ 또는 🌊 같은 이모지를 1024px PNG로 렌더 후 리사이즈 (진짜 임시방편)

## 10. 산출물 형식

- **SVG 1개** + 각 사이즈별 PNG export (16/32/48/128)
- 투명 배경 (PNG)
- 파일명: `icon-16.png`, `icon-32.png`, `icon-48.png`, `icon-128.png`
- 위치: `public/icons/` (Vite가 dist 루트로 복사)

매니페스트 등록 코드는 아이콘 받은 후 함께 작업.

## 11. 참고 (영감용)

- 비슷한 음량 익스텐션 검색: "Volume Master", "Ears", "Loudness Equalizer"
- 단, 우리는 단순 부스터 아닌 **인지 음량 평탄화**임 — 차별점 살리기
- 음향 표준 LUFS / BS.1770의 시각 모티프(EBU 미터 등)도 참고할 만함
