# 개인정보처리방침

**Chzzk Audio Auto-Scale**

최종 수정일: 2026-05-06

---

## 1. 요약

본 확장 프로그램은 사용자의 개인정보를 **수집·저장·전송하지 않습니다**.

오디오 데이터는 사용자 브라우저 내에서만 처리되며, 외부 서버나 제3자 서비스로 전송되지 않습니다.

## 2. 처리하는 데이터

### 2.1 오디오 데이터

- **출처**: 사용자가 명시적으로 활성화한 치지직(`chzzk.naver.com`) 탭의 오디오 스트림
- **처리 방식**: 크롬의 `tabCapture` API로 가로챈 신호를 Web Audio API와 AudioWorklet에서 디지털 신호 처리(DSP) — 음량 정규화(AGC), 피크 리미팅, K-weighting 필터 적용
- **저장 여부**: ❌ 저장하지 않음. 처리된 오디오는 같은 탭의 스피커 출력으로만 즉시 전달
- **외부 전송 여부**: ❌ 어떠한 외부 서버·서비스로도 전송하지 않음

### 2.2 사용자 설정값

- **항목**: AGC 파라미터(목표 음량, Silence Gate 임계값, 최대 증폭, Attack/Release 시정수)
- **저장 위치**: 크롬의 `chrome.storage.local` API — 사용자 본인의 로컬 브라우저 프로필에만 저장
- **외부 전송 여부**: ❌ 외부 동기화·서버 백업 없음 (`chrome.storage.sync` 미사용)
- **삭제 방법**: 익스텐션을 제거하거나 `chrome://extensions/` → 세부정보 → "확장 프로그램 데이터 지우기"

## 3. 외부 통신

본 확장 프로그램은 다음 어떤 것도 사용하지 않습니다:

- 외부 서버·API 호출
- 분석 도구 (Google Analytics, Mixpanel 등)
- 광고 네트워크
- 추적 픽셀·쿠키
- 원격 코드 로딩 (모든 코드는 정적으로 패키지에 포함)

## 4. 권한 사용 내역

| 권한 | 용도 |
| --- | --- |
| `tabCapture` | 치지직 탭의 오디오를 가로채 실시간 음량 정규화 처리 |
| `offscreen` | 백그라운드에서 Web Audio API를 사용하기 위한 숨겨진 문서 |
| `storage` | AGC 설정값을 사용자 로컬 브라우저에 저장 |
| `tabs` | 탭 닫힘·새로고침 감지하여 오디오 자원 정리 (메모리 누수 방지) |
| `activeTab` | 사용자가 익스텐션 아이콘을 클릭한 시점의 탭 식별 |
| `host_permissions: chzzk.naver.com` | 치지직 도메인에서만 동작하도록 명시적 제한 |

## 5. 사용자 통제권

사용자는 언제든지 다음 권리를 행사할 수 있습니다:

- **비활성화**: 익스텐션 아이콘을 클릭하여 캡처 즉시 중단
- **설정 초기화**: 팝업의 "기본값 복원" 버튼
- **데이터 삭제**: 크롬 익스텐션 관리 페이지에서 데이터 지우기 또는 익스텐션 제거
- **권한 회수**: 크롬 익스텐션 관리 페이지에서 권한 차단
